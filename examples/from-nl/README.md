# from-nl (MFI-8)

Italian natural language → FET Official `.fet` via MCP tools `fet_nl_build` / `fet_nl_patch`.

| File | Role |
|------|------|
| `antonio-orario.txt` | Raw Antonio example (chat fluff + gaps: Bianchi hours, “prima” senza sezione) |
| `antonio-orario-completo.txt` | Same scenario after typical clarifications → coherent model |
| `antonio-from-nl.fet` | Generated by `npm run smoke:nl` |

The MCP does **not** replace ChatGPT/Claude/Gemini: those clients call the tools and ask the user using `gaps[].ask`.
