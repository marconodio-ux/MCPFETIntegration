# Real-timetable smoke notes (MFI-9)

Real institute `.fet` files are **not** stored in this repository (privacy).

- Optional local copy: folder **outside** the repo via `MCPFET_PRIVATE_DIR` / `MCPFET_PRIVATE_FET`.
- Smoke: `npm run smoke:private-sample` — skips if the private sample is missing.
- Public/synthetic examples for ChatGPT: `examples/from-nl/antonio-orario*.txt`, `examples/sample-school.fet`, `examples/advise/`.

`catalog-nl-live.summary.json` is a type-coverage report (no institute roster).
